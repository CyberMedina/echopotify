# echopotify

Spotify Player — Apple Music Edition optimizado para Amazon Echo Show 8 (1280x800) y navegadores web.

## Características

- 🎵 **Spotify Web Playback SDK**: Reproducción de audio directa a través del altavoz del dispositivo.
- 🔐 **OAuth 2.0 PKCE**: Autenticación 100% en cliente, sin necesidad de backend ni almacenamiento de secretos.
- 🎨 **Apple Music Design System**: Interfaz minimalista con fondo ambiental dinámico, modo claro/oscuro adaptativo y soporte de pantalla completa.
- 📱 **Echo Show 8 Ready**: Optimizado para resolución horizontal 1280×800 y navegación táctil en Silk Browser.
